Cookie Policy

Last updated: 14 October 2026

This page explains the cookies and similar technologies used by the Padel Tens game and by this website. It should be read with our Privacy policy.

This website

This website does not set any cookies and does not use analytics or advertising. It is hosted on GitHub Pages and loads its fonts from Google Fonts; these services receive your IP address so they can deliver the page, as described in their own privacy policies.

The game

The game is an app, not a website, so it does not use browser cookies. It does use storage on your phone and identifiers that work in a similar way:

Saved game

Your progress and settings are stored on your phone so the game remembers them. This is essential for the game to work.

Invite sign-in ID

If you use Invite friends, a random sign-in ID is stored on your phone so our database can recognise your copy of the game. It is not linked to your name.

Advertising ID (Google AdMob)

Google AdMob uses your device's advertising ID to show and measure ads, and to limit how often you see the same ad. Where the law requires it (for example in the EU, the UK and Switzerland), the game asks for your consent before personalised ads are shown.

App instance ID (Google Analytics for Firebase)

Firebase uses an app instance ID to count players and understand how the game is used, for example how many people finish the tutorial.

Your choices

You can reset or delete your advertising ID in Android Settings → Google → Ads (or Settings → Privacy → Ads). You can delete everything the game stores on your phone in Profile → Reset progress, or by uninstalling the game. Your ad consent choice can be changed by clearing the game's storage in Android settings, which shows the consent form again.
